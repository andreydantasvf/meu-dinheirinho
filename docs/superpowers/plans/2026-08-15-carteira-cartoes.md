# Carteira de Cartões (carrossel estilo pilha) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the vertical list of credit cards on the `Cartões` screen into a drag-to-switch stacked carousel ("carteira"), showing the current invoice's itemized purchases/installments for whichever card is in focus.

**Architecture:** Pure frontend change in `web/`. A new `CardWallet` component wraps shadcn's `Carousel` (embla-carousel-react) to render each card as a slide, with a custom scroll-driven "peek behind" stack effect layered on top using embla's public API. A new `CardInvoiceDetails` component (Faturas Futuras + itemized current-invoice list) renders below the wallet, scoped to whichever card is focused, reusing the existing `GET /extrato?accountId=&mes=` endpoint via the existing `useExtrato` hook — no backend changes. The Extrato row markup is extracted into a shared `TransactionRow` component so both `Extrato.tsx` and the new invoice-details block render transactions identically.

**Tech Stack:** React + TypeScript + Vite (`web/`), TanStack Query, shadcn/ui, `embla-carousel-react` (new, via shadcn's `Carousel` component), Tailwind.

**Spec:** [`docs/superpowers/specs/2026-08-15-carteira-cartoes-design.md`](../specs/2026-08-15-carteira-cartoes-design.md)

## Global Constraints

- No backend changes. Reuse `GET /extrato?accountId=&mes=` (`useExtrato` in `web/src/hooks/use-transactions.ts`) for itemized current-invoice data — do not add a new endpoint.
- No new route. Everything stays on `/cartoes`; the interaction is 100% inline (drag switches focus on the same screen).
- Only new dependency: `embla-carousel-react`, installed transitively via shadcn's official `Carousel` component (`pnpm dlx shadcn@latest add carousel`). No other carousel/drag library.
- Scope is the current month's invoice only (same civil-month definition `reportsService.fatura` already uses). No navigation between past/future months in this feature.
- "Outras Contas & Bancos" section in `Cartoes.tsx` is unaffected — stays a plain vertical list.
- `web/` has no automated test framework (documented, deliberate — see `docs/web-architecture.md`). Verification for every task is `pnpm exec tsc --noEmit`, `pnpm lint`, and a manual check in the running dev server.

```tsx
import { useEffect, useState } from 'react';
import { IconPencil, IconTrash } from '@tabler/icons-react';
import { Button } from '@/components/ui/button';
import { Skeleton } from '@/components/ui/skeleton';
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  type CarouselApi,
} from '@/components/ui/carousel';
import { useFatura } from '@/hooks/use-fatura';
import { formatMoney } from '@/lib/money';
import type { Account } from '@/types/entities';

export function CardWallet({
  cards,
  onEdit,
  onDelete,
  onFocusChange,
}: {
  cards: Account[];
  onEdit: (account: Account) => void;
  onDelete: (account: Account) => void;
  onFocusChange: (accountId: string | undefined) => void;
}) {
  const [api, setApi] = useState<CarouselApi>();

  useEffect(() => {
    if (!api) {
      onFocusChange(cards[0]?.id);
      return;
    }

    function handleSelect() {
      const index = api!.selectedScrollSnap();
      onFocusChange(cards[index]?.id);
    }

    handleSelect();
    api.on('select', handleSelect);
    api.on('reInit', handleSelect);

    return () => {
      api.off('select', handleSelect);
      api.off('reInit', handleSelect);
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [api, cards]);

  return (
    <Carousel setApi={setApi} opts={{ align: 'start', containScroll: 'trimSnaps' }}>
      <CarouselContent>
        {cards.map((account) => (
          <CarouselItem key={account.id} className="basis-[85%] pl-3">
            <CardFace
              account={account}
              onEdit={() => onEdit(account)}
              onDelete={() => onDelete(account)}
            />
          </CarouselItem>
        ))}
      </CarouselContent>
    </Carousel>
  );
}

  onDelete,

  onEdit: () => void;
  onDelete: () => void;

    limite > 0 ? Math.min(100, Math.max(0, ((limite - disponivel) / limite) * 100)) : 0;

  return (
    <div className="relative overflow-hidden rounded-3xl border border-primary/20 bg-gradient-to-br from-secondary to-popover p-5 shadow-[0_8px_32px_rgba(0,0,0,0.4)]">
      <div className="flex items-start justify-between">
        <div className="flex flex-col gap-0.5">
          <span className="text-lg font-bold text-foreground tracking-tight">
            {account.nome}
          </span>
          <span className="text-xs font-medium text-muted-foreground">
            {account.diaFechamento ? `Fecha dia ${account.diaFechamento}` : 'Fatura aberta'}{' '}
            {account.diaVencimento ? `· Vence dia ${account.diaVencimento}` : ''}
          </span>
        </div>

        <div className="flex items-center gap-2">
          <span className="rounded-full bg-primary/15 px-2.5 py-0.5 text-[10px] font-semibold tracking-wider text-primary uppercase">
            ABERTA
          </span>

            variant="ghost"
            size="icon"
            onClick={onEdit}
            className="size-7 rounded-lg text-muted-foreground hover:bg-foreground/10 hover:text-foreground"
          >
            <IconPencil size={14} />
          </Button>
          <Button
            variant="ghost"
            size="icon"
            onClick={onDelete}
            className="size-7 rounded-lg text-muted-foreground hover:bg-destructive/20 hover:text-destructive"
          >
            <IconTrash size={14} />
          </Button>
        </div>
      </div>

      {isLoading && <Skeleton className="my-4 h-16 w-full rounded-2xl bg-foreground/5" />}

      {fatura && (
        <>
          <div className="my-4 flex flex-col gap-1">
            <span className="text-[11px] font-semibold tracking-[0.2em] uppercase text-muted-foreground">
              Fatura Atual
            </span>

              <span className="text-lg font-semibold text-muted-foreground">R$</span>

                {formatMoney(fatura.faturaAtual).replace('R$', '').trim()}
              </span>
            </div>
          </div>

          <div className="flex flex-col gap-2">
            <div className="h-2 w-full overflow-hidden rounded-full bg-foreground/10">

              />

              <span>Limite utilizado</span>
              <span className="font-bold text-foreground tabular-nums">
                R$ {formatMoney(fatura.limiteDisponivel).replace('R$', '').trim()} disponível
              </span>
            </div>
          </div>
        </>
      )}
    </div>
  );
}
```

### Task 4: Stack ("pilha") visual effect on `CardWallet`

**Files:**
- Modify: `web/src/components/card-wallet.tsx` (only `CardWallet`, not `CardFace`)

**Interfaces:**
- Consumes: embla's public `CarouselApi` methods — `selectedScrollSnap()`, `scrollSnapList()`, `scrollProgress()`, `on(event, cb)`/`off(event, cb)` for `'select' | 'scroll' | 'reInit'`. No change to `CardWallet`'s external props (still `{ cards, onEdit, onDelete, onFocusChange }`).

- [ ] **Step 1: Add the tween effect to `CardWallet`**

Replace the whole `card-wallet.tsx` file's top (imports + `CardWallet`) with:

```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import { IconPencil, IconTrash } from '@tabler/icons-react';
import { Button } from '@/components/ui/button';
import { Skeleton } from '@/components/ui/skeleton';
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  type CarouselApi,
} from '@/components/ui/carousel';
import { useFatura } from '@/hooks/use-fatura';
import { formatMoney } from '@/lib/money';
import type { Account } from '@/types/entities';

const MAX_PEEK = 2;
const PEEK_STEP_PX = 16;
const SCALE_STEP = 0.06;
const TRANSLATE_Y_STEP = 10;
const OPACITY_STEP = 0.35;
const OPACITY_FLOOR = 0.15;

function clamp(value: number, min: number, max: number) {
  return Math.min(Math.max(value, min), max);
}

export function CardWallet({
  cards,
  onEdit,
  onDelete,
  onFocusChange,
}: {
  cards: Account[];
  onEdit: (account: Account) => void;
  onDelete: (account: Account) => void;
  onFocusChange: (accountId: string | undefined) => void;
}) {
  const [api, setApi] = useState<CarouselApi>();
  const itemRefs = useRef<(HTMLDivElement | null)[]>([]);

  const applyStackTween = useCallback(() => {
    if (!api) return;
    const selectedIndex = api.selectedScrollSnap();
    const selectedNode = itemRefs.current[selectedIndex];
    if (!selectedNode) return;

    const selectedLeft = selectedNode.offsetLeft;
    const scrollProgress = api.scrollProgress();

    api.scrollSnapList().forEach((snapPoint, index) => {
      const node = itemRefs.current[index];
      if (!node) return;

      const diffToTarget = snapPoint - scrollProgress;

      if (diffToTarget < -0.05 || diffToTarget > MAX_PEEK + 0.5) {
        node.style.opacity = '0';
        node.style.pointerEvents = 'none';
        return;
      }

      const clamped = clamp(diffToTarget, 0, MAX_PEEK);
      const pullBack = node.offsetLeft - selectedLeft;
      const translateX = -pullBack + clamped * PEEK_STEP_PX;
      const scale = 1 - clamped * SCALE_STEP;
      const translateY = clamped * TRANSLATE_Y_STEP;
      const opacity = Math.max(1 - clamped * OPACITY_STEP, OPACITY_FLOOR);

      node.style.transform = `translateX(${translateX}px) translateY(${translateY}px) scale(${scale})`;
      node.style.opacity = String(opacity);
      node.style.zIndex = String(30 - Math.round(clamped * 10));
      node.style.pointerEvents = clamped < 0.05 ? 'auto' : 'none';
    });
  }, [api]);

  useEffect(() => {
    if (!api) {
      onFocusChange(cards[0]?.id);
      return;
    }

    function handleSelect() {
      const index = api!.selectedScrollSnap();
      onFocusChange(cards[index]?.id);
    }

    handleSelect();
    applyStackTween();
    api.on('select', handleSelect);
    api.on('select', applyStackTween);
    api.on('scroll', applyStackTween);
    api.on('reInit', applyStackTween);

    return () => {
      api.off('select', handleSelect);
      api.off('select', applyStackTween);
      api.off('scroll', applyStackTween);
      api.off('reInit', applyStackTween);
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [api, cards, applyStackTween]);

  return (
    <div className="h-[196px]">
      <Carousel setApi={setApi} opts={{ align: 'start', containScroll: 'trimSnaps' }}>
        <CarouselContent>
          {cards.map((account, index) => (
            <CarouselItem key={account.id} className="basis-[85%] pl-3">
              <div
                ref={(node) => {
                  itemRefs.current[index] = node;
                }}
                className="transition-transform duration-300 ease-out will-change-transform"
              >
                <CardFace
                  account={account}
                  onEdit={() => onEdit(account)}
                  onDelete={() => onDelete(account)}
                />
              </div>
            </CarouselItem>
          ))}
        </CarouselContent>
      </Carousel>
    </div>
  );
}
```

`CardFace` (below `CardWallet` in the same file) is unchanged from Task 3.

Why `offsetLeft` and not `getBoundingClientRect()`: `offsetLeft` reflects the element's position in normal layout flow, unaffected by any `transform` already applied to it — so recomputing on every `'scroll'` tick doesn't compound previous frames' transforms into the next calculation. `getBoundingClientRect()` would reflect the already-transformed position and create drift.

The `h-[196px]` wrapper around `<Carousel>` gives ~16px of headroom below each card face (`CardFace`'s natural height is ~180px) so the `translateY` peek offset on stacked-behind cards doesn't get clipped by the carousel viewport's `overflow-hidden` (hardcoded inside shadcn's generated `CarouselContent`, not overridable via `className`).

- [ ] **Step 1: Create `web/src/components/card-invoice-details.tsx`**

```tsx
import { useMemo, useState } from 'react';
import { useNavigate } from 'react-router-dom';
import { IconCalendar } from '@tabler/icons-react';
import { toast } from 'sonner';
import { Skeleton } from '@/components/ui/skeleton';
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
} from '@/components/ui/alert-dialog';
import { TransactionRow } from '@/components/transaction-row';
import { useCategories } from '@/hooks/use-categories';
import { useFatura } from '@/hooks/use-fatura';
import { useDeleteTransaction, useExtrato } from '@/hooks/use-transactions';
import { formatMoney } from '@/lib/money';
import { currentMonth, formatMonthLabel } from '@/lib/date';
import { ApiError } from '@/lib/api';
import type { Account, Transaction } from '@/types/entities';

export function CardInvoiceDetails({ account }: { account: Account }) {
  const navigate = useNavigate();
  const { data: categories } = useCategories();
  const { data: fatura } = useFatura(account.id);
  const {
    data: items,
    isLoading,
    isError,
  } = useExtrato({ accountId: account.id, mes: currentMonth() });
  const deleteTransaction = useDeleteTransaction();
  const [deleting, setDeleting] = useState<Transaction | undefined>(undefined);

  const categoryMap = useMemo(
    () => new Map(categories?.map((c) => [c.id, c])),
    [categories],
  );
  const sorted = useMemo(
    () => [...(items ?? [])].sort((a, b) => b.data.localeCompare(a.data)),
    [items],
  );

  async function confirmDelete() {
    if (!deleting) return;
    try {
      await deleteTransaction.mutateAsync({
        id: deleting.id,
        accountId: deleting.accountId,
      });
      toast.success('Transação excluída com sucesso');
    } catch (error) {
      toast.error(
        error instanceof ApiError ? error.message : 'Não foi possível excluir',
      );
    } finally {
      setDeleting(undefined);
    }
  }

  return (
    <div className="flex flex-col gap-4">
      {fatura && fatura.faturasFuturas.length > 0 && (
        <div className="flex flex-col gap-2 rounded-2xl border border-border bg-card p-4">
          <span className="text-[11px] font-semibold tracking-[0.2em] uppercase text-muted-foreground">
            Faturas Futuras
          </span>
          <div className="flex flex-col gap-1.5">
            {fatura.faturasFuturas.map((future) => (
              <div
                key={future.mes}
                className="flex justify-between text-xs font-medium text-muted-foreground"
              >
                <span className="flex items-center gap-1.5">
                  <IconCalendar size={13} className="text-muted-foreground" />
                  {formatMonthLabel(future.mes)}
                </span>
                <span className="font-bold text-foreground tabular-nums">
                  {formatMoney(future.total)}
                </span>
              </div>
            ))}
          </div>
        </div>
      )}

      <div className="flex flex-col gap-2">
        <span className="px-1 text-[11px] font-semibold tracking-[0.2em] uppercase text-muted-foreground">
          Itens da fatura atual
        </span>

        {isLoading && (
          <div className="flex flex-col gap-2">
            <Skeleton className="h-16 w-full rounded-2xl bg-foreground/5" />
            <Skeleton className="h-16 w-full rounded-2xl bg-foreground/5" />
          </div>
        )}

        {isError && (
          <p className="py-4 text-center text-sm font-medium text-destructive">
            Não foi possível carregar os itens da fatura.
          </p>
        )}

        {!isLoading && !isError && sorted.length === 0 && (
          <p className="py-4 text-center text-sm font-medium text-muted-foreground">
            Nenhum lançamento nesta fatura ainda.
          </p>
        )}

        {sorted.length > 0 && (
          <div className="flex flex-col rounded-2xl border border-border bg-card overflow-hidden">
            {sorted.map((transaction) => (
              <TransactionRow
                key={transaction.id}
                transaction={transaction}
                category={categoryMap.get(transaction.categoryId)}
                account={account}
                onEdit={() => navigate(`/transacoes/${transaction.id}`)}
                onDelete={() => setDeleting(transaction)}
              />
            ))}
          </div>
        )}
      </div>

      <AlertDialog
        open={Boolean(deleting)}
        onOpenChange={(open) => !open && setDeleting(undefined)}
      >
        <AlertDialogContent className="max-w-sm">
          <AlertDialogHeader>
            <AlertDialogTitle>Excluir transação?</AlertDialogTitle>
            <AlertDialogDescription>
              A transação "{deleting?.descricao}" será removida permanentemente.
            </AlertDialogDescription>
          </AlertDialogHeader>
          <AlertDialogFooter className="gap-2">
            <AlertDialogCancel>Cancelar</AlertDialogCancel>
            <AlertDialogAction
              onClick={confirmDelete}
              className="bg-destructive font-bold text-white hover:bg-destructive/90"
            >
              Excluir
            </AlertDialogAction>
          </AlertDialogFooter>
        </AlertDialogContent>
      </AlertDialog>
    </div>
  );
}
```
